# Security reports

Report a suspected vulnerability privately to adityavd97@gmail.com. Include the
revision, a minimal synthetic reproducer, and the affected command. Do not send
credentials, real message stores, or private repository contents.

There is no promised response time or security certification. Supported operating
systems and trust boundaries are documented in README.md and docs/. Public issue
reports should omit exploit details until the maintainer has assessed the report.
